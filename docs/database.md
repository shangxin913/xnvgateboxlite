# 第一阶段数据库实现

初始迁移为 `migrations/001_initial.sql`，包含 16 张应用表，不含 SQLite 自建的 `sqlite_sequence`。`docs/schema-v0.sql` 是讨论阶段的历史设计，不能用于当前程序初始化。当前实际迁移消除了节点/出口重复存储认证信息的问题，并给检测记录补齐任务外键。

## 连接和迁移

每个连接开启 `foreign_keys=ON`、`busy_timeout=5000`，数据库使用 WAL。版本存于 `schema_migrations`。只有首次空库执行迁移；已有库不会在启动时删除或重建。后续升级必须新增迁移而非重复执行 001。SQLite 为单机第一阶段使用，不适合多实例共享文件；源代码安装的数据库保存在 `/var/lib/gateboxlite/app.db`。

时间使用 UTC 的 SQLite `CURRENT_TIMESTAMP`，HTTP 层按 UTC 解释。更新接口显式写 `updated_at`，数据库没有自动更新时间触发器。

## 管理和安全

`admin_users` 保存唯一、不区分 ASCII 大小写的用户名、Argon2id 哈希、激活标志、首次改密标志和登录时间。`admin_sessions` 用管理员外键和会话 Token 的 SHA256 保存登录状态；到期/撤销的会话无效，明文 Token 仅存在 Cookie。

`secrets` 保存 Fernet 密文。加密主钥位于运行目录 `master.key`，不进入 Git；数据库与主钥必须一起备份。`nodes.secret_ref` 指向对应密文，接口返回 `has_password`，不返回密文或 secret_ref。修改连接密码会替换密文；删除节点时同一事务清理密文。主钥遗失将无法恢复代理密码，因此只备份 SQLite 不足够。

`app_settings` 是带类型信息的键值配置，保存并发、超时、健康节点过滤和刷新周期。API 通过固定字段白名单修改，不能注入任意设置或改动文件路径。`audit_logs` 保存管理员、动作、实体和时间，不记录密码、会话、订阅 Token 或完整配置。

## 来源、节点和出口

`source_snapshots` 保存来源类型、URL、抓取时间、校验摘要、接受标志、条目数和失败摘要，真实获取器留待后续实现。`nodes` 保存节点的唯一指纹、来源外键、协议、地址、端口、地区、备注、启用标志和检测摘要。第一阶段手动新增限定 manual/socks5；vpngate/openvpn 为扩展模型，约束防止混用。

节点指纹基于协议、标准化地址、端口和用户名，不含密码、显示名称或地区。更新密码不会改变节点身份；相同连接配置重复创建返回冲突，而不是插入重复节点。节点配置变更后的旧检测状态不能继续证明新连接可用。

`node_metadata` 与节点一对一，留存来源原始 JSON、配置哈希和解析版本。未知字段仅作为数据保存，不能执行为命令。当前没有候选导入执行入口。

`egresses` 是出口策略，不重复存储 host/port/username/password；SOCKS5 从关联节点读取地址和凭据。一个节点最多一个出口。本机直出 `node_id=NULL`、`kind=local`，由部分唯一索引限制为一条。所有非本机出口必须有节点外键。`is_default=1` 的部分唯一索引保证最多一个默认出口，CHECK 要求其启用；默认改变只保存编排意图，不执行系统路由变更。

第一阶段本机直出初始禁用，且不会进入客户端订阅。没有 VPS 接入监听时无法远程消费 VPS 直出；客户端配置中的 DIRECT 只是客户端自身直出，不能用来冒充 VPS 出口。

## 检测和任务框架

`jobs` 保存类型、状态、请求者、参数、结果、进度、起止时间和心跳。活动状态 queued/running 的 lock_key 受部分唯一索引保护，为后续任务互斥预留基础。`node_checks` 保存每次真实检测的节点外键、任务外键、协议、状态、延迟、出口证据和错误，删除任务只清空 job_id、保留历史。

`schedules` 保存周期、开关和执行时间。间隔至少 1800 秒；当前所有计划默认关闭，因为 Worker 尚未接入。API 不允许开启不存在的执行器，避免用户保存“运行中”却没有任何实际任务。

## 订阅

`subscription_tokens` 保存 Token 的 SHA256、名称、筛选范围、开关、使用时间和撤销时间。明文 Token 只在创建响应返回一次，丢失需要撤销重建，而不是从数据库取出。

`subscription_builds` 预留生成缓存摘要与格式；第一阶段按请求实时生成，以便启停/撤销立即生效。`subscription_access_logs` 保存订阅 ID、格式、时间和条目数，不保存 URL 或原始 Token。订阅结果包含客户端必要代理凭据，因此必须 `private,no-store`，链接及配置不可公开分享。

节点与出口必须同时启用，并且出口允许订阅才会输出。健康过滤开启后必须 `status=healthy`；当前检测器未接入，人工配置默认为 new，因此健康过滤可能返回空订阅。这是诚实行为，界面需解释原因。

## 删除行为

管理员删除级联会话；节点删除级联元数据、检测和出口，密文由应用事务清理。删除来源快照清空节点来源 ID，但保留节点。订阅通过软撤销保持访问历史；无效 Token 访问返回 404。默认出口被禁用或节点被删除时清除默认，不自动回落 VPS 直出。
