# v0.1.0 第一阶段交付

本次提供可运行的 FastAPI + SQLite 管理后台与原生中文 Web 界面，以及可移到 Ubuntu 24.04 的源代码安装和运维工具。服务仅为管理配置与订阅，不是完整 VPN Gate/Xray 数据面。

## 已实现

管理员初始化、登录、强制首次改密、哈希会话、CSRF、退出和单进程限速；节点与 SOCKS5 出口配置；SQLite WAL、密文代理密码；默认出口策略；独立订阅 Token、创建一次返回、私密预览和撤销；v2rayN/Base64 SOCKS 与 Clash/Mihomo YAML；仪表盘、候选/任务扩展入口、设置和审计。

八条管理页面是 `/`、`/login`、`/nodes`、`/egresses`、`/subscriptions`、`/tasks`、`/settings`、`/pool`。未登录管理 API 返回 401；浏览器必须真实持有 Cookie，不设预览登录绕过。

初始密码文件独立于源码包，首次登录后必须修改密码。创建后的订阅链接仅在当前标签页内存中显示一次；在途请求在退出、换会话或对话框关闭后不会重新保存私密回执。

## 验证结果

完整测试：`51 passed, 1 warning`。唯一警告来自上游 Starlette TestClient 对 anyio 的弃用引用，不是应用失败。

Python 全局类型检查：`0 errors, 0 warnings`。Python 编译检查、JavaScript 模块语法、安装/卸载 shell 语法均通过。SQLite 初始化完整性为 ok、外键检查为空；备份回归验证数据库一致性、主钥和私密权限。

实际开发 HTTP 检查：健康、登录页、样式、脚本、标志和页面路由清单均为 200；未登录仪表盘 API 为 401。完成一次只读前后端及安装链路检查；已修正资产路径、初次运行目录和在途 Token 回执三个具体问题。未进行浏览器点击测试、所有桌面客户端版本实测或用户 VPS 的安装/网络验收。

## 下一阶段

VPN Gate 实际获取与白名单解析、真实 SOCKS5/OpenVPN 出口检测、独立 Worker 和周期任务、VPN Gate 隧道与远端 VPS 接入层尚未实现。界面禁用对应操作，接口返回明确 501，计划默认关闭，不输出假健康节点。

当前 SOCKS5 订阅直接指向上游地址，由客户端直连；不经 VPS 转发。本机直出只是 VPS 路由意图，没有接入监听无法变成远端可用代理，因此不进入订阅。Clash DIRECT 是客户端自身直出，不被用于冒充 VPS。默认出口不修改系统路由。

Manus 预览仅为本次开发会话的运行界面，本次没有发布正式网站/代理服务。SQLite 与主钥应在用户 VPS 私有数据目录，或明确挂载的持久卷中保存；不依赖托管容器的临时文件系统。
